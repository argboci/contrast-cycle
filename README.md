# Contrast

Free 8-week functional bodybuilding program as an installable web app: tempo supersets, conditioning
with a built-in workout timer, a movement library of ~940 demo videos grouped by muscle, swap options
per movement, and a training log that stays on your phone.

Open the site on your phone and use **Add to Home Screen** (iPhone: Share > Add to Home Screen;
Android: menu > Install app / Add to Home screen).

Movement demo videos: Marcus Filly / Functional Bodybuilding on YouTube. Inspired by his Functional
Body Composition method. Independent, free project; not affiliated with or endorsed by him.
